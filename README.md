Bienvenue dans le deuxieme jour du stage.
Aujourd'hui les consignes sont un peu differentes. Il s'agit d'un CTF.
Tu dois retrouver un flag dans le dossier de l'exercice. A toi de trouver la bonne commande pour le faire apparaitre. Seul trois exercices ont leurs flags a l'exterieure. L'indice te mettra sur la voie.
Toutes les commandes permettant de faire apparaitre le FLAG 
sont a noter dans le fichier flag.txt sous la forme :

FLAGXX{commandes utilisees} - ou XX est le numero du FLAG correspondant au numero de l'exercice.

Les commandes doivent afficher le FLAG et seulement le flag, sur une seule ligne, le reste n'est pas important :

ex 1 de resultat de cmd attendu:
Le flag est : XXXXXXXXXXX

ex 2 de resultat de cmd attendu: 
FLAG{XXXXXXXXXX}

Il n'est pas possible d'acceder a l'exercice suivant sans resoudre le precedent.
Le code pour l'exercice suivant est le flag precedent.

Bon courage.
