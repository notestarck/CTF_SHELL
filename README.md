Bienvenue dans le deuxième jour du stage. Aujourd'hui, les consignes sont un peu différentes. Il s'agit d'un CTF. Tu dois retrouver un flag dans le dossier de l'exercice. À toi de trouver la bonne commande pour le faire apparaître. Seuls trois exercices ont leur flag à l'extérieur. L'indice te mettra sur la voie.

Toutes les commandes permettant de faire apparaître le FLAG doivent être notées dans le fichier flag.txt sous la forme :

  FLAGXX{commandes utilisées}

où XX est le numéro du FLAG correspondant au numéro de l'exercice.

Les commandes doivent afficher le FLAG, et seulement le FLAG, sur une seule ligne ; le reste n'est pas important.

Exemple 1 de résultat de commande attendu :
  Le flag est : XXXXXXXXXXX

Exemple 2 de résultat de commande attendu :
  FLAG{XXXXXXXXXX}

Il n'est pas possible d'accéder à l'exercice suivant sans résoudre le précédent. Le code pour l'exercice suivant est le flag précédent.

Bon courage.
